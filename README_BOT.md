# Бот-сервер AI Comfort Signal

## Что должно лежать в репозитории

```
signal-bot/
├── bot.py              — сам бот
├── requirements.txt    — зависимости
├── Procfile            — команда запуска
└── cards/
    ├── 01_cover.png
    ├── 02_live.png
    ├── 03_breakdown.png
    ├── 04_journal.png
    └── 05_math.png
```

## Переменные окружения

| Имя | Значение | Обязательна |
|---|---|---|
| TG_TOKEN | токен от @BotFather | да |
| APP_URL | https://ваш-логин.github.io/signal-app/ | да |
| TD_KEY | ключ twelvedata.com | нет |
| BRIEF_HOUR | час утренней сводки по Киеву, например 8 | нет |

## Команды бота

- /start — карточки функционала и кнопка терминала
- /brief — сводка по рынку прямо сейчас
- /app — открыть терминал
- /stop — отключить утренние сводки

Сводка уходит один раз в сутки и только по будням.
