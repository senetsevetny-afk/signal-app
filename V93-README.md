# MARKET AI V93 — unified preview build

Built on the working V92/V91 Academy codebase with the V92 language patch applied.

## Added in this build
- unified premium dark trading-terminal background from startup through main UI;
- contextual ambient market motion with Reduced Motion support;
- expanded strategy catalog connected to the existing weighted-factor engine;
- common V93 analysis contract for signal/journal/Academy integration;
- Forex, Crypto, Stocks and OTC architecture (actual instruments still require a real quote feed);
- compact collapsible Profile sections for Settings and Bot/App;
- XP/Level premium progress visualization and animation;
- result-scene hooks for win/loss UI;
- global language architecture for 10 languages, preserving the existing Academy i18n layer;
- existing onboarding and Academy retained rather than duplicated.

## Important
OTC/live assets are never fabricated. Full OTC/stock/crypto coverage depends on the real data source/API connected to the app. News/Fundamental mode requires a verified event/news source before it can influence a real signal.
